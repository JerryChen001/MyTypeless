| D-028 | **在线更新：发现新版本先提示，用户确认后在应用内下载，下载完提示重启更新。** 发布地址为不用登录即可读取的公开地址（见 D-029），存放版本说明 `latest-mac.yml` 与各版本的 zip / DMG。应用启动 1 分钟后与之后每 6 小时检查一次（设置 → 关于「自动检查更新」，默认开，可关；也可随时手动检查）；自动检查只读取版本说明，不发送任何用户数据，失败时不打扰。发现新版本时系统通知一次（每个版本一次），托盘、侧栏、关于里显示；下载、重启都需用户点击；录音、会议或纪要整理中拒绝重启；下载完没重启则下次退出时安装。自动安装由 Squirrel.Mac 替换应用，要求新版本与当前应用用同一证书签名（本机自签名证书 `.vendor/signing/`），失败时提示下载 DMG 手动安装。发布（上传安装包）由 `npm run release` 完成、需人工确认，版本号必须比已发布的大。这是可选的检查，不是使用依赖，不违反 D-003。确认：项目负责人（选择“发现新版本后提示，确认下载时使用内置下载，完成后提示重启更新”），2026-10-17 |

| D-036 | **Windows 安装包与在线更新（扩展 D-028、D-032 到 Windows）。** Windows 版为 x64 的 NSIS 一键安装包，装到当前用户（`%LOCALAPPDATA%\Programs\MyTypeless`，不要管理员权限、不弹 UAC），卸载时保留设置、历史与模型；没有代码签名证书，首次安装 SmartScreen 会提示“未知发布者”。在线更新规则同 D-028：读取同一发布地址的 `latest.yml`，用户确认后应用内下载，重启时静默运行新版本安装包并重新打开应用。发布者不需要 Windows 电脑：`npm run release` 传完 Mac 文件后触发 GitHub Actions 的 `release-windows.yml`，在 Windows 机器上按同一提交打包，把安装包与 `latest.yml` 传到同一个草稿 Release，两边都传完才转正式（Windows 构建失败则不发布，`--no-windows` 只发 Mac）；人工门禁仍是那一次 `--yes`。该工作流也可在 Actions 页面手动运行（不填标签），只生成安装包供下载测试。确认：Windows 移植贡献者提议（安装包 + 在线更新、CI 出包、一键安装到当前用户），项目负责人合并 PR 时确认，2026-10-17 |

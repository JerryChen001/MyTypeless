# 未决事项

本文件只登记会改变用户可见结果、数据结构、隐私或发布方式、且尚未被确认的问题。这是 B 项的唯一登记处。裁决后在[决策登记](decisions/decision-register.md)新增 D 项，并把 B 项移入“已关闭事项”。

| ID | 当前默认/已知边界 | 需要的最终输入 |
| --- | --- | --- |
| B-002 | 只采集焦点应用名/bundleId 做风格适配；不读屏幕文字、URL、光标前后文 | 是否提供“光标前后文作为润色上下文”的可选功能；默认值与是否需要每应用开关 |
| B-003 | 历史无限期保存在本地，主窗口只显示最近 200 条 | 是否需要保留期限（如 30/90 天自动清理）或条数上限，以及是否默认开启 |
| B-008 | 会议需求不含实时翻译（[会议需求](requirements/meeting.md)“不包含”）；系统声音（D-033）只用于会议转写，听写的翻译模式只听麦克风 | 是否支持把系统声音（线上会议、视频等）翻译成另一种语言（如英译中）；形式：会中逐句译文（每句一次 LLM 请求，实测慢电脑 + 中转约 2 秒/句，有调用成本）还是会后整篇翻译；目标语言、开关与入口（会议内 / 独立模式）；只把转写文字发给用户自配的 LLM（同 D-016），不发录音。Windows 用户真机试用后提出，2026-10-17 |

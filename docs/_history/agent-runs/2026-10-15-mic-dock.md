# 2026-10-15 采集不到声音、Dock 图标消失

## 现象

安装 2026-10-15 的包后：辅助功能与麦克风都已授权，但内置麦克风和耳机都采集不到声音；应用运行后 Dock 无图标、⌘Tab 切不到。

## 诊断（用已安装的应用 + 调试端口）

- 进程类型 `lsappinfo`：`UIElement`。原因：浮动条与回答浮卡调用 `setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })`，Electron 默认会把进程转成 UIElement（稳定性修复那一轮引入）。
- 麦克风：授权 `granted`、轨道 `live`、未静音，但峰值恒为 0。系统默认输入设备是 **Screaming Bee**（变声器虚拟设备，未运行送音软件时输出纯静音）；逐个设备测试：内置麦克风峰值 0.046，Screaming Bee 为 0。应用一直使用系统默认输入。
- 排除：16kHz AudioContext 跨采样率接入（合成 48k 正弦波接入 16k 上下文峰值 1.0，正常）。

## 改动

- 浮动条 `type: 'panel'`；两处 `setVisibleOnAllWorkspaces` 加 `skipTransformProcessType: true` → 进程类型 `Foreground`。
- 麦克风：新增设置 `micDeviceId`（默认自动）；自动模式跳过常见虚拟输入设备、优先内置麦克风；开麦 0.6 秒全是纯零自动换设备并提示；`devicechange` 后重新选择；主窗口新增麦克风下拉（标注虚拟设备）。

## 验证

- 打包版经 LaunchServices 启动（隔离数据目录，沿用证书签名下的授权）：进程类型 `Foreground`；语音提问模式录 2 秒，识别出环境语音“好”，在需要 LLM Key 处停止（未写入）。

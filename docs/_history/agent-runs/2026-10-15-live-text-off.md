# 2026-10-15 个人模式：说话时默认不显示文字（D-023）

## 背景

用户反馈个人模式的交互变了，希望回到之前的样子；经确认指的是“说话时胶囊上方实时出字”（D-013 加入）。

## 改动

- 新设置项 `showLiveText`（默认关）：只有打开时录音中才把识别中的文字发给胶囊，并做说话不停时的限频预览；关闭时停顿处仍在后台识别（松手等待不变），胶囊只显示波形。
- 旧设置项 `livePreview` 不再生效：保存设置时会把所有项写入 settings.json，旧值 true 无法区分是否用户选择（本机即为 true）；改用新字段让所有人回到默认关闭。
- 关闭时“识别中”状态也不带文字。设置页开关改绑新字段、文案改为“说话时在胶囊上方显示识别中的文字（默认关闭）”。

## 验证

`npm run typecheck`、`npm run test`（62 项）、`npm run build`、`npm run docs:check` 通过。打包版 20261015.1922 隔离实例（旧设置 `livePreview: true`，假麦克风播放真人对话）：14 秒录音中胶囊文字始终为空；打开 `showLiveText` 后同样录音文字逐步出现（对照）。测试以取消结束，不向其他应用写入。

# 2026-10-21 切换模式时首页误显示“兜底模式”

## 现象

Windows 真机上首页“快捷键引擎”偶尔显示“兜底模式（按住说话退化为按一下开始/结束）”，过一会自己恢复。

## 原因

在运行中的应用里临时记录快捷键助手的启动、退出与状态查询，复现时的记录：

- 切换个人 / 会议模式 → 主窗口保存设置 `appMode`；
- 主进程每次保存设置都调用 `hotkeys.registerAll()`：先挂上兜底快捷键、杀掉并重启 `mt-hotkey`，就绪前 `isNativeReady()` 为 false；
- 切换模式同时跳回首页、立即查询状态，正好落在这几十毫秒里（助手 38 毫秒后就绪），首页显示兜底；首页只在切过来或窗口获得焦点时刷新，所以一直显示到下次刷新（这次 5 秒后）。

快捷键实际只断了几十毫秒，不是助手崩溃，与平台无关（macOS 同样会重启助手）。

## 改动

`bindings.ts` 新增 `hotkeysChanged`：比较四个模式实际生效的快捷键（听写没设时用 `hotkeyKey`，与 `HotkeyController.registerAll` 取值一致）；保存设置后只在它为真时重新注册。

## 验证

- `test/bindings.test.ts` 新增用例：快捷键不变 / 某个模式改键 / 听写没设时 `hotkeyKey` 改变。
- typecheck / test / build / docs:check 通过。

# 2026-10-15 每次打开应用都弹钥匙串授权

## 现象与原因

用户反馈每次打开应用都要求授权钥匙串（“MyTypeless Safe Storage”）。

- 读得太频繁：`settingsGet`（主窗口打开、保存设置后都会调用）为了显示 `hasApiKey`/`apiKeyMasked` 把两个 Key 都解密一遍；启动时检查云端识别配置也解密；每次听写无论是否润色都读 LLM Key。每次解密都访问钥匙串。
- 授权不跨安装包：应用用本机自签名证书签名，没有 Apple 团队 ID，钥匙串对这类程序的“始终允许”只认当前这一个安装包；开发期间频繁重新打包，每装一个新包首次访问都会再问。

## 修复

- `hasKey`/`keyMask`：判断有无 Key、显示掩码只看加密文件里是否有该项，不解密；掩码改为 `••••末4位`（末 4 位在设置时单独存放，非机密；旧数据显示 `••••`）。
- 只在真正调用云端服务时解密（润色开启的听写、翻译/改写/提问、会议纪要、云端识别），本次运行内缓存，每次启动最多访问一次。
- 结果：不开润色、只用本地识别时完全不访问钥匙串；开了润色时，每次启动首次润色访问一次，点“始终允许”后同一安装包不再询问。

## 未解决（需人工决定）

每装一个新安装包，首次用到 Key 时仍会询问一次。根治需要：Developer ID 签名（稳定团队 ID，GAP-009，人工门禁）或改变 Key 的存放方式（涉及 D-002）。已向用户说明并请其选择。

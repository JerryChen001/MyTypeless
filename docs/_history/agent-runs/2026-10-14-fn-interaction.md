# 2026-10-14 按住 Fn 说话的交互

## 范围

关联 D-010、GAP-012。负责人要求默认主键用 Fn：按住说话、轻按免手持。刻意没做：拦截 Fn 键本身的系统事件（可能导致修饰键状态卡住），改为引导用户把「按下 🌐 键时」设为「无操作」。

## 目标交互

按住 Fn 说话；轻按开始免手持、再按一下结束；选中文字后按快捷键即语音改写；Fn+空格 语音提问；Fn+Shift 翻译。

## 改动

- `mt-hotkey`：按住 fn 时按下空格 / Shift 且组成注册组合 → 先 abort 听写再发组合 down；其他键 → abort 并放行；新增 `shift` 组合键名。
- `mt-focus --selected-text`：辅助功能读取选区（0.3 秒超时，不碰剪贴板）。
- `src/main/key-press.ts`（新，纯逻辑）：按住 / 轻按（< 300ms）免手持 / abort / 模式键；`hotkeys.ts` 改用它；兜底模式下 Fn 主键改用 ⌥+空格。
- 会话：`enterHandsFree`、`handsFree` 进度字段；开口同时读取选区，有选中文字转为改写；写入成功后 350ms 收起。
- 浮动条：重做为底部居中小胶囊（波形 / 免手持取消完成 / 模式标签 / 处理三点 / 完成 ✓ / 出错提示），透明区域点击穿透。
- 主窗口：去掉“按住/触发”二选一，新的用法说明与默认键；Fn 与系统 🌐 键冲突提示 + 打开键盘设置。
- 设置与迁移：默认 `fn` / `fn+space` / `fn+shift` / 改写留空；旧默认（⌥+空格 等）启动时自动迁移。

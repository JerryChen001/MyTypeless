# 2026-10-15 识别准确度与授权保留

## 范围

用户反馈：重新打包后又“未授权”；本地识别不准。关联 GAP-013、B-006、A-005。

## 原因

- 未授权：用户直接运行 `release/` 里的新包；adhoc 签名每次打包都变，系统按 cdhash 认人，旧授权失效（系统设置里开关仍显示为开）。
- 识别不准（推断，历史库为空无法取样）：① 按下快捷键到麦克风出声约 160～340ms（getUserMedia），按住即说的人开头一两个字被截；② 自写的 48k→16k 取平均重采样有混叠、浏览器通话降噪损伤语音细节；③ 未配置 LLM，同音错字无法靠润色修正。

## 实测（M2 Pro）

| 样本 | Whisper turbo（无提示词） | SenseVoice int8 2025-09-09 |
| --- | --- | --- |
| 普通话真人 zh.wav | 开放时间早上九点至下午五点（应为“开饭”） | 饭时间早上九点至下午五点（漏字） |
| 英语真人 en.wav | 完全正确 | 全大写、多处错词 |
| 中英混说（合成） | 带标点、DeepSeek 正确 | 无标点、“DEEP SCK” |
| 粤语真人 | 转为书面中文 | 地道粤语 |
| 耗时 | 约 1.2s（常驻） | 0.6～1.3s（每次启动程序） |

- 给 whisper 加“使用简体中文和中文标点”提示词：英文语音被译成中文乱码、出现“请不吝点赞”幻觉，耗时 5～22s —— 撤回。
- 结论：不采用 SenseVoice；保留 Whisper turbo，改进前端与标点。

## 改动

- 采集：AudioContext 16kHz（浏览器重采样）、关闭降噪/回声消除、100ms 分片；麦克风保持就绪 60s + 0.3s 预录（设置可关，B-006）。
- 文本：`src/main/text.ts` 中文语境标点规整（带测试）。
- 签名：`scripts/setup-signing.sh` 生成本地自签名证书（独立钥匙串，`.vendor/signing/`），`scripts/sign-app.cjs` 用它签名，指定要求为“标识 + 证书”，重新打包后授权保留；主窗口「重置授权」清除本应用旧记录。

## 验证

- `npm run test` 26/26；隔离实例：16kHz 采集两次会话音频均送达，第二次复用保持就绪的麦克风，无报错。
- 未验证：真人真机识别效果（GAP-013）。

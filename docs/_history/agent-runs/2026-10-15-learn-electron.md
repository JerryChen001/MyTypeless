# 2026-10-15 自动词典在 Claude 等 Electron 应用里学不到词

## 背景

用户反馈测了几轮语音输入，词典里没有自动学到的词。只看结构统计：今天 13 条听写，12 条写入 Claude 桌面版（Electron），1 条写入本应用；词典 0 条；学习计数只有 1 个常用专有名词候选（出现 1 次），没有任何“改正”计数；两个学习开关都开着。

## 原因

- 追踪修改（D-012）写入后第 8、25 秒用 `mt-focus --caret-context` 读光标附近文字；它通过“系统焦点元素”找输入框，而 Electron / Chromium 应用默认不公开辅助功能树，系统焦点返回 -25204 → 退出码 5 → 追踪立即停止。前台为 Chrome 时实测同样退出码 5（辅助功能权限正常）。
- 常用专有名词只统计英文专有名词、出现 3 次才收录；13 条里只有 3 条含英文。

## 修复

`mt-focus` 的 `focusedElement`：系统焦点问不到时改问前台应用的焦点元素，仍问不到则对该应用设置 `AXManualAccessibility = true` 再问。`--caret-context` 与 `--selected-text`（选中即改写）共用。读取范围不变（只读光标附近与插入长度相当的一段 / 选中的文字）。

## 验证

用本应用的隔离实例（Electron）作目标：新启动的实例输入框写入测试文字并聚焦，旧逻辑系统焦点 -25204、应用焦点 -25212；新 `mt-focus --caret-context` 退出码 0，读出光标附近文字与光标位置正确。没有对用户正在使用的 Chrome / Claude 做读取测试；向真实应用写入并改字的完整流程未自动测试（会向用户前台应用键入），待真机验证。

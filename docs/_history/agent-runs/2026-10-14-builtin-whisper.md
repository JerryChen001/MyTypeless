关联 D-009、A-007、GAP-011。负责人决定以本地 whisper.cpp 为主、装完即用，模型不进安装包、安装后提示下载。刻意没做：边说边识别（GAP-010）、本地 SenseVoice。

## 选型实测（M2 Pro，`say` 合成的中文 6.8 秒 / 中英混说 9.9 秒）

| 方案 | 结果 |
| --- | --- |
| base / small-q5_1 | 0.15～0.55 秒，但输出繁体、有错字（会议室→会议式、带上→戴上），提示词无效 |
| large-v3-turbo-q5_0，`language=auto` | 1.7 秒，简体、全对 |
| large-v3-turbo-q5_0，`language=zh` | 0.9 秒，简体、全对；英文语音仍输出英文 |
| 按请求缩小 `audio_ctx` | 部分取值 0.5 秒且正确，相邻取值输出乱码，弃用 |
| 改 beam / 线程数 | 无明显影响（瓶颈是编码器，auto 会多跑一次语言检测） |

## 改动

- `scripts/build-whisper.sh`：whisper.cpp v1.9.5 静态编译 `whisper-server` → `native/bin/mt-whisper`（7.9MB，Metal 内嵌，只依赖系统框架）；`predist` 自动执行，同版本跳过。
- `native/text-helper.swift` → `mt-text`：系统 ICU 繁简转换。
- `src/main/whisper/`：模型目录与语言/字形解析、断点续传下载（多源、校验、取消）、引擎进程管理（随机端口、预热、闲置退出、崩溃重启）、模型管理。
- 会话：内置引擎缺模型时不开始录音并打开主窗口；开口即预热；分段合并；错误码中文化。
- 设置：新用户默认 `builtin`；升级时“云端但无 Key”迁移为 `builtin`；云端默认模型改为 `gpt-transcribe`，LLM 默认改为 `gpt-6-luna`（原 gpt-4o 系列已公告下线）。
- 主窗口：首次使用下载横幅、模型列表（下载/取消/使用/删除）、识别语言与中文简繁。
